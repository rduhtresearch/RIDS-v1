# RIDS-v1

## Setup

Follow these steps the first time you run the app.

1. Open the project in RStudio.

2. Open `R/SETUP/new_setup.R`.

3. Update these values in the script so they match your machine or shared drive:
   - `DB_DIR`
   - `ICT_UPLOAD_DIR`
   - `EDGE_OUTPUT_DIR`
   - `ADMIN_USERNAME`

4. Run the full `R/SETUP/new_setup.R` script.

5. Wait for setup to finish.
   It will:
   - install missing R packages
   - create `config.R`
   - create the required folders
   - initialise the DuckDB database
   - print an admin setup token in the console

6. Copy the admin setup token shown in the console.

7. Open `app.R` and run the app.

8. On the login screen, click `Set your password`.

9. Enter:
   - the setup token
   - your new password

10. Go back to the login screen and sign in with the `ADMIN_USERNAME` you set in `R/SETUP/new_setup.R`.

## Notes

- If you need to change the database or folder paths later, update `R/SETUP/new_setup.R` and run it again.
- `config.R` is generated by the setup script. Do not edit it manually.
